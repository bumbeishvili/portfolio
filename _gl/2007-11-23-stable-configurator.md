Built an interactive stable planning tool with synchronized 2D plan and 3D view workflows.

Technical highlights:
- Three.js/WebGL rendering pipeline for plan and scene views
- modular component system for bays and functional areas
- grid snapping, dimensions, and placement interactions
- state-driven editor actions for selection and layout updates
